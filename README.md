# Interface Theme

Jasny arkusz Standalone z układem responsywnym, czytelnymi listami i większymi kontrolkami dotykowymi. Przeznaczony do interfejsów o zgodnej strukturze HTML.

## Użycie

Adres arkusza:

```text
https://aqnar.github.io/interface-theme/theme.css
```

Wklej adres w pole **Standalone CSS stylesheet** w ustawieniach interfejsu. Pole **External CSS stylesheet** pozostaw puste, zapisz ustawienia i odśwież stronę.

## Zasoby

Arkusz zawiera bazowy układ, paletę i zasoby ikon. Czcionki WOFF2 i obraz są osadzone bezpośrednio jako adresy danych, bez odwołań do zewnętrznego serwera zasobów. Oryginalne informacje o bibliotekach i ich autorach pozostają w CSS.

## Publikacja

GitHub Pages publikuje katalog główny gałęzi `main`. Plik `.nojekyll` pozwala udostępniać pliki statyczne bez przetwarzania szablonów.
